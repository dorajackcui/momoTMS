# Archive

This directory preserves legacy material that may still be useful for historical context.

## Usage Rules

- Do not treat archive files as the source of truth for the current runtime.
- When archive content conflicts with active docs under `docs/` or with the code, prefer current code and active docs.
- Preserve meaning when moving material into the archive; avoid rewriting historical documents into new guidance.
